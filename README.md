## 🧠 Domain Knowledge — Lending Technology

Hands-on experience across the NBFC loan lifecycle, from sourcing to disbursement:

| Lending stage | What I've worked on | Systems & APIs |
|---|---|---|
| **Sourcing & CRM** | CRM rollout for the sales team, lead-generation infrastructure, automated customer journeys | Sales CRM · WhatsApp Business API |
| **Onboarding & KYC** | Identity and business verification flows, CKYC compliance coordination | Karza KYC · CKYC · Gridlines (Udyam / MSME) |
| **Financial Analysis** | Consent-based bank data retrieval and bank-statement analysis | Account Aggregator (Sahamati) · Perfios |
| **Credit Assessment** | Bureau report parsing, credit dashboards, AI-assisted bureau analysis | CRIF High Mark · CIBIL · Anthropic API |
| **Decisioning** | Rules-engine integration into the underwriting flow | Business Rules Engine |
| **Origination Platform** | Leading IT for a merger-driven LOS build — requirements, vendor coordination, UAT | Loan Origination System |
| **Disbursement & Payments** | Tranche-disbursement modules, online fee collection | Easebuzz payment gateway |
| **Data & Infrastructure** | Production database access governance, AWS environments, data-lake design exploration | AWS EC2 / S3 · PostgreSQL · Parquet · Athena |

**Also comfortable with:** EMI / IRR and reducing-balance loan math (Python & Excel), Google Apps Script automation, IT vendor evaluation, and training L1 support staff.
